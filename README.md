### Exercise 3: Rest API (make for both direct queries to database and gorm)
#### Create a REST API with routes for GET, POST, PUT, and DELETE.
1.	Get Users (GET /users): A handler to fetch all users from the users table.
2.	Create User (POST /user): A handler to insert a new user into the users table.
3.	Update User (PUT /user/{id}): A handler to update an existing user in the users table.
4.	Delete User (DELETE /user/{id}): A handler to delete a user from the users table.
